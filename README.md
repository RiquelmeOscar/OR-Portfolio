# Oscar Alexandro Riquelme — Portfolio

Landing personal de Quality Engineering: perfil, proyectos y contacto.

**Stack:** HTML + CSS + JavaScript vanilla. Sin build, sin dependencias.

## Estructura

```
/
├── index.html        # Landing one-page (Inicio · Proyectos · Sobre mí · Contacto)
├── css/style.css     # Estilos
├── js/main.js        # Smooth scroll
└── assets/           # Recursos estáticos
```

## Desarrollo local

Abrir `index.html` en el navegador, o servir con cualquier servidor estático:

```bash
npx serve .
```

## Proyectos

Los case studies viven en sus propios repositorios en GitHub. Los links de la sección
Proyectos apuntan hoy a `github.com/RiquelmeOscar` y se actualizarán a cada repo
cuando se publiquen.

## Deploy

Compatible con GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
